# C Day 98 – Bank Transaction Management System

## Description
A menu-driven C application for managing bank accounts and performing basic transactions using structures and file handling.

## Features
- Create bank accounts.
- Display account details.
- Deposit money.
- Withdraw money.
- Check account balance.
- Save account records in a text file.

## Files
- `bank.c` – Main C program.
- `accounts.txt` – Sample account records.
- `temp.txt` – Temporary file created during updates.

## How to Compile
```bash
gcc bank.c -o bank
```

## How to Run
On Windows:
```bash
bank.exe
```

On Linux:
```bash
./bank
```

## Concepts Used
- Structures
- Functions
- File Handling
- Record Searching
- File Updating
- Menu-driven Programming

## Note
This is an educational project. Do not use it for real financial transactions.
